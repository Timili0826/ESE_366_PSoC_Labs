# New run outputs

New CPU and CUDA runs write here. Historical experiments are indexed in
[results](../results/README.md); historical CPU working files are preserved in
[outputs_snapshot](../results/cpu/outputs_snapshot/).

CPU training and plotting retain their existing `outputs/` paths. Run training
before plotting. Use explicit, fresh CUDA output directories as shown in the
[root README](../README.md). This directory is not globally ignored by Git.
