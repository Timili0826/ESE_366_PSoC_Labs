7D-4:
The equation converts the signed sine-wave value into the format required by the DAC. It rounds the value to an integer, uses the absolute value for the magnitude, adds 32 when the original value is negative to encode polarity, and adds 128 as the base DAC control value.

7D-5:
.literal and .endliteral define a block of constant data in program memory, allowing the sine-wave lookup table to be stored and accessed by the program without being executed as code.
